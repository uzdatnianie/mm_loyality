# MM Loyalty

To jest repozytorium modułu Loyalty Points dla Drupal 11 i Commerce 3.

## Co zawiera

- moduł w katalogu `mm_loyality/`,
- podstawową konfigurację,
- kontrolery, formularze, encje, subskrybentów zdarzeń i usługi.

## Dokumentacja

Pełna dokumentacja modułu znajduje się w pliku [mm_loyality/README.md](mm_loyality/README.md).

## Szybki start

1. Skopiuj katalog modułu do środowiska Drupal.
2. Włącz moduł i zależności.
3. Skonfiguruj ustawienia w panelu administracyjnym.
